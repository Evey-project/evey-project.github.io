    API des plugins¶

    Les points d'accès de gestion des plugins et des intégrations par webhook.

    Spécifications¶

    Spécification Contenu
    admin_plugin.swagger.json Installer, activer, désactiver, désinstaller des plugins. Configuration et journaux des plugins. Environnements d'exécution.
    webhook.swagger.json Création, lecture, modification et suppression des webhooks, historique des envois
    plugin_prefs.swagger.json Les préférences par utilisateur de l'interface d'un plugin (la permission prefs)

    Développer un plugin¶

    Les plugins dialoguent avec le serveur Evey en gRPC. Le guide complet est dans la documentation des plugins, notamment :

    • le cycle de vie d'un plugin (installation, activation, configuration, désactivation, désinstallation) ;
    • les événements disponibles ;
    • le schéma de configuration ;
    • l'isolation de sécurité (seccomp, isolation des processus).
